What it is / is not

A compressed map of Brandon Sandoval’s Maths of Quantum Mechanics onto one hardware question. Not a transcript dump. Not a claim that phones compute in superposition.

world → ADC → host CPU/GPU
  → DAC + IQ pulses
  → [ QPU : |ψ⟩ ↦ U(t)|ψ⟩ ]
  → readout → bits → display

Only the bracket is quantum. A FET is not a drop-in qubit.
